4Хэрэглэгчид: .env тохиргоо

USER1_, USER2_… гэж нэмэхэд автоматаар шинэ хэрэглэгч бий болно.

# ---- Хэрэглэгч 1 (та, админ) ----
USER1_NAME=amar
USER1_ROLE=admin
USER1_MARKETS=crypto,fx
USER1_TELEGRAM_CHAT_ID=...
USER1_BINANCE_KEY=...
USER1_BINANCE_SECRET=...
USER1_OANDA_TOKEN=...
USER1_OANDA_ACCOUNT=...

# ---- Хэрэглэгч 2 ----
USER2_NAME=bat
USER2_MARKETS=fx
USER2_OANDA_TOKEN=...
USER2_OANDA_ACCOUNT=...
USER2_RISK_PER_TRADE=0.005   # 1%-иас бага байж болно, их байж болохгүй
⚙️ Ажиллах зарчим

5 минут тутам .env-ийг шалгаж, шинэ USER3_ олдвол танд мэдэгдээд автоматаар асаана. Хүн бүр зөвхөн түлхүүрээ оруулсан зах зээлдээ арилжаална.

🔑 Нууц үг

.env-д бичигдэхгүй. main.py user password bat командаар тохируулж, hash хэлбэрээр хадгална.

👑 admin

Бүх хэрэглэгч, бүх зах зээл, системийн тохиргоо

👤 user

Зөвхөн өөрийн данс, өөрийн арилжаа

7Ажиллаж байхад нь аюулгүй шинэчлэх

1. Git + GitHub

Бүх өөрчлөлт хадгалагдаж, хэзээ ч буцаах боломжтой

2. Зах зээл бүр тусдаа service

crypto-brain, fx-brain, web, scheduler. Нэг нь унасан ч бусад нь ажиллана

3. Автомат тест

Risk guard зөв үү, backtest гэнэт өөрчлөгдсөн үү

4. Хувилбарын тэмдэглэгээ

Арилжаа бүр ямар код, ямар стратегиар хийгдсэнийг хадгална

5. Стратеги = shadow-оор

Шинэ стратеги шууд идэвхждэггүй, эхлээд shadow болж туршигдана

6. Тохиргоо ≠ код

Хэрэглүүр нэмэх, timeframe солих нь config.yaml-д. Код өөрчлөхгүй
